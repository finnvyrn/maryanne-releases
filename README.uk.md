## Українська

### Читайте книги EPUB і PDF. Слухайте природними голосами.

Maryanne — це програма для читання EPUB і PDF, яка також читає ваші книги вголос природними голосами синтезу мовлення. Просто відкрийте книгу й почніть слухати. Перетворення на аудіокнигу не потрібне.

Обліковий запис не потрібен. Без реклами. Читайте й слухайте безкоштовно.

### Читайте й слухайте по-своєму

- Читайте електронні книги EPUB і документи PDF в одному застосунку.
- Слухайте книги природними голосами синтезу мовлення.
- Стежте за текстом завдяки підсвічуванню речень під час читання Maryanne.
- Обирайте офлайн-голоси, щоб слухати без підключення до інтернету.
- Налаштовуйте швидкість читання та відтворення.
- Встановлюйте таймер сну для читання й прослуховування перед сном.

### Ваша особиста бібліотека електронних книг

- Відкривайте й читайте власні файли EPUB і PDF.
- Знаходьте та слухайте безкоштовну класику суспільного надбання.
- Досліджуйте колекцію книг, що постійно зростає.
- Зберігайте прогрес читання та історію прослуховування на своєму пристрої.

### Безкоштовна програма для читання та прослуховування книг

Насолоджуйтеся читанням і прослуховуванням в одному застосунку. Чи читаєте ви електронну книгу, досліджуєте класичну літературу або слухаєте книгу перед сном, Maryanne допомагає легко насолоджуватися книгами по-своєму.

Дізнайтеся більше: https://maryanne.app

## Релізи

Доступні файли для кожного релізу:

- пакет MSIX для Windows x64
- метадані Windows App Installer
- контрольні суми SHA-256
- Linux x86_64 AppImage
- контрольні суми SHA-256
- метадані `.zsync` AppImage після створення

Завантаження AppImage використовують незмінні файли релізів із версіями.

Канали оновлень для комп’ютера:

- [Appcast для Linux](appcast-linux.xml)
- [Appcast для macOS](appcast-macos.xml)

Настільні клієнти Linux і macOS читають платформний Appcast із гілки `main`. Додавайте нові елементи на початок відповідного Appcast лише після публікації відповідних файлів релізу на GitHub. Значення `sparkle:version` має відповідати версії тегу релізу без початкової `v`, а платформне значення `sparkle:os` має бути в кожному елементі.

Користувачі Windows встановлюють із [Maryanne.appinstaller](Maryanne.appinstaller). Файл App Installer посилається на незмінний файл MSIX поточного релізу й вмикає фонову перевірку оновлень. Зберігайте його постійну URL-адресу та оновлюйте версію й URI файлу релізу для кожного випуску Windows.

Пакет AUR `maryanne-bin` використовує ці незмінні файли релізу.
