## Română

### Citiți cărți EPUB și PDF-uri. Ascultați cu voci naturale.

Maryanne este un cititor EPUB și PDF care vă citește și cărțile cu voce tare, folosind voci naturale pentru transformarea textului în vorbire. Deschideți pur și simplu o carte și începeți să ascultați. Nu este necesară conversia în audiobook.

Nu este necesar un cont. Fără reclame. Citiți și ascultați gratuit.

### Citiți și ascultați în felul dumneavoastră

- Citiți cărți electronice EPUB și documente PDF într-o singură aplicație.
- Ascultați cărți cu voci naturale pentru transformarea textului în vorbire.
- Urmăriți textul prin evidențierea propozițiilor în timp ce Maryanne citește.
- Alegeți voci offline pentru a asculta fără conexiune la internet.
- Reglați viteza de citire și redare.
- Setați un temporizator de oprire pentru citit și ascultat înainte de culcare.

### Biblioteca dumneavoastră personală de cărți electronice

- Deschideți și citiți propriile fișiere EPUB și PDF.
- Descoperiți și ascultați gratuit clasici din domeniul public.
- Explorați o colecție de cărți în continuă creștere.
- Păstrați progresul lecturii și istoricul ascultărilor pe dispozitivul dumneavoastră.

### Un cititor de cărți electronice și un ascultător de cărți gratuit

Bucurați-vă de citit și ascultat într-o singură aplicație. Fie că citiți o carte electronică, explorați literatura clasică sau ascultați o carte înainte de culcare, Maryanne vă ajută să vă bucurați ușor de cărți în felul dumneavoastră.

Aflați mai multe: https://maryanne.app

## Instalare

### Snap Store

[Maryanne în Snap Store](https://snapcraft.io/maryanne)

```bash
sudo snap install maryanne
```

### AUR pentru Arch Linux

[maryanne-bin pe AUR](https://aur.archlinux.org/packages/maryanne-bin)

Utilizare `yay`:

```bash
yay -S maryanne-bin
```

Utilizare `paru`:

```bash
paru -S maryanne-bin
```

## Lansări

Artefacte disponibile pentru fiecare lansare:

- pachet MSIX pentru Windows x64
- metadate Windows App Installer
- sume de control SHA-256
- Linux x86_64 AppImage
- sume de control SHA-256
- metadate `.zsync` AppImage atunci când sunt generate

Descărcările AppImage folosesc fișiere de lansare imuabile și versionate.

Fluxuri de actualizare pentru desktop:

- [Appcast Linux](../appcast-linux.xml)
- [Appcast macOS](../appcast-macos.xml)

Clienții desktop Linux și macOS citesc Appcastul specific platformei din ramura `main`. Adăugați elementele noi în partea de sus a Appcastului corespunzător numai după publicarea fișierelor de lansare potrivite pe GitHub. Valoarea `sparkle:version` trebuie să fie egală cu versiunea etichetei lansării fără `v` inițial, iar valoarea `sparkle:os` a platformei trebuie să apară în fiecare element.

Utilizatorii Windows instalează de la [Maryanne.appinstaller](../Maryanne.appinstaller). Fișierul App Installer indică spre fișierul MSIX imuabil al versiunii curente și activează verificările de actualizări în fundal. Păstrați URL-ul stabil și actualizați versiunea și URI-ul fișierului de lansare pentru fiecare lansare Windows.

Pachetul AUR `maryanne-bin` folosește aceste fișiere de lansare imuabile.
