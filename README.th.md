## ไทย

### อ่านหนังสือ EPUB และ PDF ฟังด้วยเสียงที่เป็นธรรมชาติ

Maryanne คือโปรแกรมอ่าน EPUB และ PDF ที่อ่านหนังสือของคุณออกเสียงด้วยเสียงแปลงข้อความเป็นเสียงที่ฟังดูเป็นธรรมชาติ เพียงเปิดหนังสือแล้วเริ่มฟังได้ทันที ไม่ต้องแปลงเป็นหนังสือเสียง

ไม่ต้องมีบัญชี ไม่มีโฆษณา อ่านและฟังได้ฟรี

### อ่านและฟังในแบบของคุณ

- อ่านอีบุ๊ก EPUB และเอกสาร PDF ได้ในแอปเดียว
- ฟังหนังสือด้วยเสียงแปลงข้อความเป็นเสียงที่ฟังดูเป็นธรรมชาติ
- อ่านตามด้วยการไฮไลต์ประโยคขณะที่ Maryanne อ่าน
- เลือกเสียงออฟไลน์เพื่อฟังโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต
- ปรับความเร็วในการอ่านและการเล่นได้
- ตั้งเวลาปิดเครื่องสำหรับการอ่านและฟังก่อนนอน

### ห้องสมุดอีบุ๊กส่วนตัวของคุณ

- เปิดและอ่านไฟล์ EPUB และ PDF ของคุณเอง
- ค้นพบและฟังวรรณกรรมคลาสสิกที่เป็นสาธารณสมบัติได้ฟรี
- สำรวจคอลเลกชันหนังสือที่เพิ่มขึ้นเรื่อย ๆ
- เก็บความคืบหน้าในการอ่านและประวัติการฟังไว้บนอุปกรณ์ของคุณ

### โปรแกรมอ่านอีบุ๊กและฟังหนังสือฟรี

เพลิดเพลินกับการอ่านและการฟังในแอปเดียว ไม่ว่าคุณจะอ่านอีบุ๊ก สำรวจวรรณกรรมคลาสสิก หรือฟังหนังสือก่อนนอน Maryanne ก็ช่วยให้คุณเพลิดเพลินกับหนังสือในแบบของคุณได้ง่ายขึ้น

## ติดตั้ง

### Snap Store

[Maryanne บน Snap Store](https://snapcraft.io/maryanne)

```bash
sudo snap install maryanne
```

### AUR ของ Arch Linux

[maryanne-bin บน AUR](https://aur.archlinux.org/packages/maryanne-bin)

การใช้งาน `yay`:

```bash
yay -S maryanne-bin
```

การใช้งาน `paru`:

```bash
paru -S maryanne-bin
```

## รุ่นเผยแพร่

ไฟล์ที่มีให้สำหรับแต่ละรุ่น:

- แพ็กเกจ MSIX สำหรับ Windows x64
- ข้อมูลเมตาของ Windows App Installer
- ค่าแฮช SHA-256
- Linux x86_64 AppImage
- ค่าแฮช SHA-256
- ข้อมูลเมตา `.zsync` ของ AppImage เมื่อสร้างแล้ว

การดาวน์โหลด AppImage ใช้ไฟล์รุ่นเผยแพร่ที่มีเวอร์ชันและไม่เปลี่ยนแปลง

ฟีดอัปเดตเดสก์ท็อป:

- [Appcast ของ Linux](appcast-linux.xml)
- [Appcast ของ macOS](appcast-macos.xml)

ไคลเอนต์เดสก์ท็อป Linux และ macOS อ่าน Appcast เฉพาะแพลตฟอร์มจากสาขา `main` เพิ่มรายการล่าสุดไว้ด้านบนของ Appcast ที่ตรงกันหลังจากเผยแพร่ไฟล์รุ่นเผยแพร่ที่ตรงกันบน GitHub แล้วเท่านั้น ค่า `sparkle:version` ในแต่ละรายการต้องตรงกับเวอร์ชันของแท็กรุ่นเผยแพร่โดยไม่มี `v` นำหน้า และต้องมีค่า `sparkle:os` ของแพลตฟอร์มในทุกรายการ

ผู้ใช้ Windows ติดตั้งจาก [Maryanne.appinstaller](Maryanne.appinstaller). ไฟล์ App Installer ชี้ไปยังไฟล์ MSIX ที่ไม่เปลี่ยนแปลงของรุ่นปัจจุบันและเปิดใช้การตรวจสอบการอัปเดตเบื้องหลัง รักษา URL ถาวรไว้และอัปเดตเวอร์ชันกับ URI ของไฟล์รุ่นเผยแพร่สำหรับ Windows แต่ละรุ่น

แพ็กเกจ AUR `maryanne-bin` ใช้ไฟล์รุ่นเผยแพร่ที่ไม่เปลี่ยนแปลงเหล่านี้
