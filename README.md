# Maryanne Releases

Public binary distribution for [Maryanne](https://maryanne.app), a closed-source Flutter ebook reader.

This repository contains release assets only. Source code remains private.

Available artifacts per release:

- Linux x86_64 AppImage
- SHA-256 checksums
- AppImage `.zsync` metadata when generated

AppImage downloads use immutable versioned release assets.

AUR packaging is maintained separately as `maryanne-bin` and consumes these immutable release assets.
