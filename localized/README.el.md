## Ελληνικά

### Διαβάστε βιβλία EPUB και PDF. Ακούστε με φυσικές φωνές.

Το Maryanne είναι πρόγραμμα ανάγνωσης EPUB και PDF που διαβάζει επίσης τα βιβλία σας δυνατά με φυσικές φωνές μετατροπής κειμένου σε ομιλία. Απλώς ανοίξτε ένα βιβλίο και ξεκινήστε να ακούτε. Δεν χρειάζεται μετατροπή σε ηχητικό βιβλίο.

Δεν απαιτείται λογαριασμός. Χωρίς διαφημίσεις. Διαβάστε και ακούστε δωρεάν.

### Διαβάστε και ακούστε με τον δικό σας τρόπο

- Διαβάστε ηλεκτρονικά βιβλία EPUB και έγγραφα PDF σε μία εφαρμογή.
- Ακούστε βιβλία με φυσικές φωνές μετατροπής κειμένου σε ομιλία.
- Παρακολουθήστε την ανάγνωση με επισήμανση προτάσεων καθώς διαβάζει το Maryanne.
- Επιλέξτε φωνές εκτός σύνδεσης για ακρόαση χωρίς σύνδεση στο διαδίκτυο.
- Ρυθμίστε την ταχύτητα ανάγνωσης και αναπαραγωγής.
- Ρυθμίστε χρονοδιακόπτη ύπνου για ανάγνωση και ακρόαση πριν τον ύπνο.

### Η προσωπική σας βιβλιοθήκη ηλεκτρονικών βιβλίων

- Ανοίξτε και διαβάστε τα δικά σας αρχεία EPUB και PDF.
- Ανακαλύψτε και ακούστε δωρεάν κλασικά έργα του δημόσιου τομέα.
- Εξερευνήστε μια συλλογή βιβλίων που μεγαλώνει.
- Κρατήστε την πρόοδο ανάγνωσης και το ιστορικό ακρόασης στη συσκευή σας.

### Δωρεάν πρόγραμμα ανάγνωσης και ακρόασης βιβλίων

Απολαύστε την ανάγνωση και την ακρόαση σε μία εφαρμογή. Είτε διαβάζετε ένα ηλεκτρονικό βιβλίο, εξερευνάτε την κλασική λογοτεχνία είτε ακούτε ένα βιβλίο πριν κοιμηθείτε, το Maryanne κάνει εύκολη την απόλαυση βιβλίων με τον δικό σας τρόπο.

Μάθετε περισσότερα: https://maryanne.app


## Εγκατάσταση

### Snap Store

[Το Maryanne στο Snap Store](https://snapcraft.io/maryanne)

```bash
sudo snap install maryanne
```

### AUR του Arch Linux

[maryanne-bin στο AUR](https://aur.archlinux.org/packages/maryanne-bin)

Χρήση `yay`:

```bash
yay -S maryanne-bin
```

Χρήση `paru`:

```bash
paru -S maryanne-bin
```

## Εκδόσεις

Διαθέσιμα αρχεία ανά έκδοση:

- πακέτο MSIX για Windows x64
- μεταδεδομένα Windows App Installer
- αθροίσματα ελέγχου SHA-256
- Linux x86_64 AppImage
- αθροίσματα ελέγχου SHA-256
- μεταδεδομένα `.zsync` του AppImage όταν δημιουργούνται

Οι λήψεις AppImage χρησιμοποιούν αμετάβλητα αρχεία έκδοσης με αριθμό έκδοσης.

Ροές ενημερώσεων υπολογιστή:

- [Appcast Linux](../appcast-linux.xml)
- [Appcast macOS](../appcast-macos.xml)

Οι υπολογιστές-πελάτες Linux και macOS διαβάζουν το Appcast της πλατφόρμας τους από τον κλάδο `main`. Προσθέτετε τα νεότερα στοιχεία στην κορυφή του αντίστοιχου Appcast μόνο αφού δημοσιευτούν τα αντίστοιχα αρχεία έκδοσης στο GitHub. Η τιμή `sparkle:version` πρέπει να είναι ίση με την έκδοση της ετικέτας έκδοσης χωρίς το αρχικό `v`, ενώ η τιμή `sparkle:os` της πλατφόρμας πρέπει να υπάρχει σε κάθε στοιχείο.

Οι χρήστες Windows εγκαθιστούν από [Maryanne.appinstaller](../Maryanne.appinstaller). Το αρχείο App Installer δείχνει στο αμετάβλητο αρχείο MSIX της τρέχουσας έκδοσης και ενεργοποιεί ελέγχους ενημερώσεων στο παρασκήνιο. Διατηρήστε το σταθερό URL του και ενημερώνετε την έκδοση και το URI του αρχείου έκδοσης σε κάθε έκδοση των Windows.

Το πακέτο AUR `maryanne-bin` χρησιμοποιεί αυτά τα αμετάβλητα αρχεία έκδοσης.
